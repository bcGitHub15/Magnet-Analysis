# Magnet Mapping Analysis

First thing is a model analysis of what to expect from a mapper that runs along 5 sets of lines each of which consists of two sections at 18° to each other. This is FredLines.ipynb. NOTE that I made a mistake with the size of translations and only moved the lines 3.9 *milli*meters instead of centimeters. This means that all the effects of translation are ten time smaller than we expect in the real system.

Next thing is Gordon's take on a portion of the same problem. He got the offsets right but worked only in the trap coordinate frame. This is GordonLines.ipynb.
